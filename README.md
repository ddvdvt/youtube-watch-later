# Смотреть позже — чистка и очередь

**Статус: 1.0.0, готово к отправке в Chrome Web Store.** Тексты карточки, ответы для проверки, скриншоты и промо-картинки — в [`store/`](store/). Адрес сайта бренда уже указан: `BASE = 'https://ddvdvt.github.io/'` в [`extension/lib/brand.js`](extension/lib/brand.js) и `homepage_url` в манифесте.

⚠️ **Проверено только на локальных фикстурах.** Войти в аккаунт YouTube при разработке было нельзя, поэтому загрузка и удаление на настоящем списке «Смотреть позже» не прогонялись. Перед публикацией пройдите [чек-лист на своём аккаунте](#чек-лист-перед-публикацией-на-своём-аккаунте).

Расширение для Chrome, Edge и Firefox (десктоп) для тех, у кого в «Смотреть позже» скопились тысячи видео:

1. **Чистка списка «Смотреть позже»** — загрузить весь список целиком, посмотреть, что в нём, выбрать фильтрами, что удалить, и удалить безопасно: с резервной копией, пробным прогоном, порциями, с паузой, отменой и продолжением после перезагрузки.
2. **«Воспроизвести далее» и своя очередь** — кнопки на превью видео и в меню правой кнопки мыши, панель очереди на странице видео, автопереход к следующему видео из очереди и сочетание клавиш.

Скрытием Shorts и рекомендаций это расширение не занимается — это делает отдельное расширение автора «Видео без мусора».

## Чистка «Смотреть позже»

Откройте `youtube.com/playlist?list=WL` (нужно войти в аккаунт) — справа внизу появится кнопка **«Разобрать „Смотреть позже“»**.

- **Весь список.** YouTube показывает по 100 видео; расширение само проходит все продолжения (пауза 0,2–0,45 с между страницами) и показывает прогресс «Загружено 1 200 из ~5 012». На локальных фикстурах 5000 видео загружаются за ~17 с; на настоящем YouTube ожидаемо 30–60 с (50 запросов плюс паузы). Вкладка не подвисает (в e2e-тесте самая длинная пауза главного потока при загрузке 5000 видео — около 60 мс).
- **Сводка:** всего, просмотрено, недоступно, Shorts, общая длительность.
- **Фильтры** (можно сочетать, режим «все условия сразу» или «любое»): просмотренные от N % (по умолчанию 90 %), недоступные (удалённые, скрытые), Shorts, каналы (выбор из списка с количеством и поиском), длительность от/до (в минутах), «всё, кроме первых K в списке», слова в названии (через запятую). Плюс ручные галочки у любого видео поверх фильтров.
- **Живой предпросмотр:** «Выбрано: 1 079 из 4 873», список с прокруткой (виртуальный — в DOM ~20 строк даже для 10 000 видео), переключатель «только выбранные».
- **Встроенное в YouTube «Удалить просмотренные»** (меню ⋮ списка) упомянуто прямо в панели: оно удаляет всё просмотренное разом и без предпросмотра. Здесь — порог просмотра, недоступные, каналы, длительность, позиция, слова, предпросмотр и резервная копия.

### Безопасность

- **Пробный прогон** проходит весь план (сколько запросов, сколько видео) и не отправляет ни одного запроса — это проверяет e2e-тест.
- **Перед любым удалением** автоматически скачивается резервная копия **всего** загруженного списка в JSON (`watch-later-backup-ГГГГ-ММ-ДД-ЧЧММ.json`: позиция, id видео, название, канал, длительность, процент просмотра, флаги, отметка «выбрано для удаления»). Последние три копии хранятся ещё и в расширении (их можно скачать в настройках как JSON или CSV). Кнопки «Скачать копию JSON» и «Скачать таблицу CSV» есть и в панели.
  - Почему автоматически только JSON, а CSV — по кнопке: Chrome при двух скачиваниях подряд с одной страницы спрашивает «Разрешить сайту скачивать несколько файлов?»; если пользователь откажет, второй файл молча пропадёт. Важнее, чтобы гарантированно сохранился файл, по которому можно восстановить.
- **Подтверждение** с точным числом («Удалить 265 видео из „Смотреть позже“?»), первыми названиями, скоростью и примерным временем.
- **Порции и паузы.** Первый запрос — всегда с одним видео (проба формата). Дальше «Обычно» — по 25 видео раз в ~1,5 с (±30 %), «Бережно» — по 10 раз в ~3 с. При ответе 429 («слишком много запросов»), 5xx или обрыве сети — экспоненциальная пауза (с учётом `Retry-After`, до 5 минут); после 6 неудач подряд удаление само встаёт на паузу. 401/403 — остановка с просьбой обновить страницу. Если YouTube не принял порцию целиком (400), те же видео отправляются по одному, а не принятые помечаются «пропущено».
- **Пауза, отмена, продолжение после перезагрузки.** Состояние сохраняется после каждой порции; после перезагрузки страницы кнопка становится «Продолжить удаление». Повторных удалений не бывает (проверено e2e).
- **Возврат из резервной копии** (из файла JSON/CSV или из копий в расширении): видео, отмеченные в копии как удалённые, добавляются обратно тем же действием, что и кнопка «Смотреть позже» на превью (`ACTION_ADD_VIDEO`). Честно: порядок и «дата добавления» будут другими, недоступные видео вернуть нельзя, видео, которые уже есть в списке, пропускаются.
- **В очередь вместо удаления:** выбранные видео можно поставить в очередь — по порядку, вперемешку или с конца списка (обычно это «сначала старые»).

### Что именно отправляется в YouTube и почему

Расширение делает **ровно те запросы, что и сама страница «Смотреть позже»** в вашей вкладке, и никаких других. Их отправляет маленький скрипт [`src/page/bridge.js`](extension/src/page/bridge.js), который работает в контексте страницы (manifest `"world": "MAIN"`), потому что только там доступен `window.ytcfg` — клиентский контекст YouTube.

| Что | Запрос | Тело |
|---|---|---|
| Первая страница списка | `POST https://www.youtube.com/youtubei/v1/browse?prettyPrint=false` | `{context, browseId: "VLWL", params: "wgYCCAA%3D"}` — `params` — значение пункта YouTube «Показать недоступные видео»; если YouTube его не примет, запрос повторяется без него |
| Следующие страницы | тот же адрес | `{context, continuation: "<токен из предыдущего ответа>"}` |
| Удаление | `POST https://www.youtube.com/youtubei/v1/browse/edit_playlist?prettyPrint=false` | `{context, playlistId: "WL", actions: [{action: "ACTION_REMOVE_VIDEO", setVideoId}, …]}` — до 25 действий в одном запросе. Действие берётся из пункта меню «Удалить из „Смотреть позже“» самого видео; если его нет — `ACTION_REMOVE_VIDEO_BY_VIDEO_ID` с `removedVideoId` (так делает переключатель «Смотреть позже» на превью) |
| Возврат | тот же адрес | `{context, playlistId: "WL", actions: [{addedVideoId, action: "ACTION_ADD_VIDEO"}, …]}` — как кнопка «Смотреть позже» на превью |

- `context` — `ytcfg.get('INNERTUBE_CONTEXT')` страницы; заголовки — как у веб-клиента: `X-Origin`, `X-Youtube-Client-Name`, `X-Youtube-Client-Version`, `X-Goog-AuthUser` (`SESSION_INDEX`), `X-Goog-Visitor-Id`, `X-Goog-PageId` (для брендовых аккаунтов, `DELEGATED_SESSION_ID`).
- **Авторизация.** Веб-клиент YouTube подписывает такие запросы заголовком `Authorization: SAPISIDHASH <время>_<SHA-1("<время> <SAPISID> <origin>")>` (плюс варианты `SAPISID1PHASH`/`SAPISID3PHASH` и суффикс `_u`, если в `ytcfg` есть `DATASYNC_ID`). Скрипт страницы вычисляет тот же заголовок тем же способом: читает значение cookie `SAPISID` из `document.cookie` **этой страницы** и использует его только для этого заголовка в запросе к `www.youtube.com`. Значение нигде не сохраняется, не попадает в расширение (контент-скрипт и фон его не видят) и никуда больше не отправляется. API `chrome.cookies` не используется, разрешения на cookies нет. Сами cookies к запросу добавляет браузер (`credentials: 'same-origin'`).
- **Белый список.** Скрипт страницы принимает от расширения только эти четыре вида запросов: `browse` с `browseId: "VLWL"` или токеном продолжения, `edit_playlist` с `playlistId: "WL"` и только действиями удаления/добавления видео (не более 100 за раз). Всё остальное отклоняется без сетевого запроса (unit- и e2e-тесты).
- Ничего, кроме списка «Смотреть позже», не читается: ни история, ни подписки, ни другие плейлисты.
- Других серверов нет: ни автора, ни третьих лиц.

## «Воспроизвести далее» и очередь

У YouTube есть своя очередь в мини-плеере, но управлять ею снаружи надёжно нельзя (это внутреннее состояние приложения без публичного API). Поэтому у расширения **своя очередь**, она хранится в `chrome.storage.local` и живёт между вкладками и перезапусками.

- **Кнопки на превью.** При наведении на превью видео (главная, поиск, каналы, «Смотреть позже», колонка рядом с видео) в его левом верхнем углу появляются «⏭ Далее» и «≡+ В очередь». На маленьких превью — только значки (подписи в подсказках и `aria-label`). Одна плавающая панель на всю страницу — её не ломают перерисовки YouTube.
- **Правая кнопка мыши** по любой ссылке на видео (`/watch`, `/shorts`, `youtu.be`) на YouTube: «Воспроизвести далее» и «В конец очереди». Это же — путь с клавиатуры: фокус на ссылке → клавиша контекстного меню или Shift+F10.
- «Воспроизвести далее» ставит видео первым; если оно уже в очереди — переносит вперёд, а не дублирует.
- **Панель очереди** на странице видео (правый нижний угол, сворачивается): порядок перетаскиванием или стрелками ↑/↓, удаление, «Следующее ▶», «Очистить», «Сейчас из очереди: …».
- **Автопереход:** когда видео закончилось, открывается следующее из очереди — и при выключенном автовоспроизведении YouTube. Переход внутри приложения (без перезагрузки), если не вышло за 1,5 с — обычная загрузка страницы. Конец рекламной вставки не считается (проверяется `ad-showing` у плеера). Выключается в настройках.
- **Сочетание клавиш Alt+Shift+Q** — «следующее из очереди» в активной вкладке YouTube (или в новой вкладке). Alt+Shift+N Chrome назначить не даёт (проверено), а Alt+Shift+Q не занято ни Chrome, ни YouTube (у YouTube свои клавиши без Alt). Поменять: `chrome://extensions/shortcuts` (ссылка есть в настройках).
- **Попап:** очередь с переносом и удалением, «Следующее ▶», кнопка «Открыть чистку списка».

## Установка для проверки

1. Chrome → `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное» → папка `extension/`.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Доступ к `https://www.youtube.com/*` | Показать панель чистки на странице «Смотреть позже», кнопки на превью и панель очереди; отправлять запросы списка и удаления от имени открытой страницы. Других сайтов нет, iframe и встроенные плееры не трогаются. |
| `storage` | Настройки, очередь, состояние незавершённого удаления (для продолжения после перезагрузки), три последние резервные копии. Только на этом устройстве. |
| `contextMenus` | Пункты «Воспроизвести далее» и «В конец очереди» в меню правой кнопки мыши по ссылкам на видео на YouTube. |

Нет `downloads` (резервная копия скачивается обычной ссылкой `blob:` со страницы), нет `cookies`, `tabs`, `scripting`, `webRequest`, `history`. Сочетание клавиш (`commands`) разрешения не требует.

## Приватность

Без аккаунта, аналитики и рекламы. Данные — только в `chrome.storage.local`. Запросы — только к `www.youtube.com`, те же, что делает сама страница. Подробно — [PRIVACY.md](PRIVACY.md).

## Firefox

Сборка для Firefox делается из тех же исходников `extension/` — меняется только манифест (скрипт `scripts/firefox.mjs`):

```
npm run zip:firefox       # dist/youtube-watch-later-<версия>-firefox.zip (для AMO) + распакованная сборка dist/firefox/
npm run lint:firefox      # web-ext lint по распакованной сборке
npm run test:e2e:firefox  # e2e в установленном Firefox (временный профиль, локальные страницы и поддельный API)
```

**Установка для проверки:** `npm run zip:firefox` → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение…» → `dist/firefox/manifest.json`. Временное дополнение удаляется при закрытии Firefox.

**Чем отличается от Chrome:**

- Нужен Firefox **140+** (ESR 140): с этой версии есть `data_collection_permissions` — обязательное для новых дополнений на AMO поле «какие данные собираются» (у нас `none`). Для Firefox для Android — 142+ (но расширение рассчитано на десктоп).
- Фон — event page вместо service worker (тот же файл `src/background.js`). Мост в мире страницы (`content_scripts` с `"world": "MAIN"`) Firefox поддерживает с 128 — e2e проверяет загрузку 5000 видео через него, подпись SAPISIDHASH и отказ для чужих запросов.
- **Доступ к youtube.com в Firefox можно не выдать или отозвать** (MV3: about:addons → дополнение → «Разрешения»). Тогда окно расширения пишет «Нет доступа к youtube.com» и показывает кнопку «Разрешить доступ к YouTube» (`permissions.request`; после согласия вкладка YouTube перезагружается).
- Пункты контекстного меню на ссылках на видео, `Alt+Shift+Q` (не занято Firefox), «Изменить» у сочетания в настройках — открывает about:addons → «Управление горячими клавишами» (`commands.openShortcutSettings`).
- Перетаскивание в очереди в e2e Firefox проверяется событиями drag/drop внутри страницы (WebDriver не запускает нативный drag); вживую — проверить руками.
- Идентификатор дополнения: `youtube-watch-later@ddvdvt.github.io`.

Тексты и ответы для AMO — [`store/amo.md`](store/amo.md).

## Разработка

```
npm install          # только playwright-core (без скачивания браузера)
npm test             # unit-тесты (node --test)
npm run test:e2e     # e2e в установленном Chromium на локальных фикстурах
npm run zip          # dist/youtube-watch-later-1.0.0.zip с проверкой архива
npm run store:images # скриншоты и промо в store/ (реальный интерфейс на фикстурах)
npm run locales      # _locales из scripts/locales.src.mjs
npm run icons        # иконки
```

- Чистая логика — в [`extension/lib/`](extension/lib/): разбор ответов YouTube (`wl-parse.js`, понимает текущий формат `lockupViewModel` и старый `playlistVideoRenderer`), фильтры (`wl-filter.js`), резервные копии (`backup.js`), планировщик порций и пауз (`runner.js`), очередь (`queue.js`), селекторы превью (`selectors.js`).
- **Если YouTube изменит формат:** загрузка списка сообщит «Похоже, YouTube изменил формат списка… Ничего не удалено», если в ответе нет понятных элементов, а заголовок говорит, что видео есть. Править — `lib/wl-parse.js` (+ фикстура `e2e/fixtures/wl-data.mjs`). Кнопки на превью завязаны только на «ссылка на видео, внутри которой картинка» — это переживает большинство перерисовок; правая кнопка мыши работает всегда.
- **E2E** (`e2e/smoke.mjs`): локальный «видеосайт» и поддельный API, который проверяет заголовок `SAPISIDHASH` так же, как он строится, записывает каждый запрос и умеет отвечать 429. Проверяется: загрузка 5000 видео за 50 запросов без подвисаний, виртуальный список, фильтры, пробный прогон без запросов, скачивание копии до удаления, пробный запрос из одного видео, порции по 25 и интервалы ≥ 0,9 с, пауза (нет запросов), перезагрузка и продолжение без повторов, `Retry-After` после 429, отмена (остальное не тронуто), возврат из копии, кнопки на превью, панель очереди (стрелки и перетаскивание), автопереход внутри приложения, игнор рекламы и выключенного автоперехода, попап, настройки, отказ моста в чужих запросах.
- Нельзя проверить автоматически: настоящий YouTube с входом, сочетание клавиш (синтетические нажатия не доходят до команд браузера), меню правой кнопки.

## Чек-лист перед публикацией (на своём аккаунте)

Делайте на основном профиле Chrome, где вы вошли в YouTube. Начните с маленького фильтра.

1. Загрузить распакованное `extension/`, открыть `https://www.youtube.com/playlist?list=WL`. Справа внизу — «Разобрать „Смотреть позже“».
2. «Загрузить весь список». Сверить «всего» с числом в заголовке YouTube. Если меньше — проверить, видны ли недоступные (значит `params` «показать недоступные» не сработал — это не страшно, но запишите).
3. Пролистать предпросмотр: названия, каналы, длительность, «100 %» у просмотренных, «недоступно» у удалённых, отметка Shorts.
4. Включить «Недоступные», **вручную оставить галочки только у 5 видео** (или выбрать канал с 5 видео) → «Пробный прогон» → в DevTools → Network не должно быть запросов `edit_playlist`.
5. «Удалить 5» → подтвердить → должен скачаться `watch-later-backup-….json` (откройте, проверьте 5 строк с `"selected": true`). Удаление: 2 запроса (1 + 4). В Network: `POST /youtubei/v1/browse/edit_playlist` → ответ 200 с `"status": "STATUS_SUCCEEDED"`.
6. Обновить страницу YouTube — этих 5 видео в списке нет; остальное на месте.
7. «Вернуть из резервной копии» → копия от только что → «Вернуть N» → видео снова в списке (на верху или внизу — по настройке YouTube).
8. Средний объём: 100–300 видео, «Бережно»; посреди — «Пауза», обновить страницу, «Продолжить удаление».
9. Очередь: на главной навести на превью → «Далее»; правой кнопкой по ссылке → «В конец очереди»; открыть видео → панель очереди → перемотать видео в конец → открылось следующее из очереди. Alt+Shift+Q — следующее сразу. Проверить с автовоспроизведением YouTube вкл. и выкл., а также в плейлисте (`&list=…`).
10. Если что-то пошло не так: скачанный JSON — ваша копия; в настройках расширения есть ещё три последних.
